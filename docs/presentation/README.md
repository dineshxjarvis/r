## Status language

- **Prototype:** the SIH implementation the team intends to demonstrate.
- **Production:** the target Ministry-scale platform.
- **Roadmap:** designed but not claimed as working.
- **Simulated:** a working interface driven by labelled synthetic data or a mock external feed.

Never describe a roadmap or simulated function as already deployed.

## SIH scoring alignment

Official SIH guidance evaluates novelty, complexity, clarity/detail, feasibility, practicability, sustainability, scale of impact, user experience and future progression. The master deck maps every criterion to a slide. Source: [Official SIH College SPOC Guidelines](https://sih.gov.in/letters/Guidelines-College-SPOC.pdf).
